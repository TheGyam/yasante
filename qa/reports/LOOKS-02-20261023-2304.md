## Other observations

1. **Environment variable conflict**: Shell environment variable `DEBUG=release` conflicted with `python-decouple` boolean parsing (`DEBUG = config("DEBUG", default=False, cast=bool)`) in `backend/config/settings/base.py`, causing `manage.py` invocations in `env-up` and `web-up` to fail initially. Invoking with `env -u DEBUG` resolved the conflict by allowing decouple to read `DEBUG=True` from `backend/.env`.
2. **Missing native module `ExpoLocalization` in dev-client APK**: The installed dev client (`dev-client.apk`, dated Oct 10) does not contain native bindings for `expo-localization` (which was introduced as a dependency in the 20-10 upstream merge). On app launch, module import `src/shared/lib/region.ts:1` throws `[Error: Cannot find native module 'ExpoLocalization']`.
3. **Router layout crash in React Native**: Metro logs also recorded `ERROR [Error: <Screen /> component in 'default export' at 'app/(client)/(home,planner,profile)/_layout' must have a 'name' prop when used as a child of a Layout Route.]` in `src/shared/ui/TabStack.tsx:13:5`. Because of these unhandled errors, the React Native view hierarchy failed to mount and both devices displayed a blank screen, preventing any user interaction.
