## Other observations
- Soft keyboard dismissal: On text input screens (e.g. `care-plan-form`), tapping action buttons while an input field is focused dismisses the soft keyboard rather than activating the button tap. Sending `qadb key BACK` to dismiss the keyboard beforehand resolves this.
- Route Protection: `yasante:///onboarding/quiz` is guarded by `<Stack.Protected guard={!entered}>` where `entered = isAuthenticated || onboarded`. Once an account is signed in, this route cannot be deep-linked into, preventing subsequent quiz testing.
- JWT Access Token Expiration: Access tokens expire after 15 minutes. The frontend handles token refresh via `POST /api/auth/refresh-token/` seamlessly, but the initial expired request returns a 401 in `server.log`, triggering a strict QA check failure on steps that span across the 15-minute mark (C4 and B6).
- Shelf "Add your own product" entry point: On `Add to your shelf`, the `shelf-add-own` button is only rendered in the list footer when a search query is non-empty (`results.length > 0 && q.trim()`). Opening the screen directly from empty search requires either typing a search query or navigating to `/shelf/new-product`.
