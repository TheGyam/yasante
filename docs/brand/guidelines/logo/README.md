# Logos

`yasante-app-icon-master.jpg` is the reference artwork: the rendered icon with its silk shading, grain and glow. Every SVG here is a vector trace of it for print, small sizes and code; when they disagree, the master wins.

Inks: the silk files use the `silk-*` palette (#f8d7de to #4d2f31) and `petal-smoke` (#736064); `yasante-mark-rose.svg` is #f8d7de and #efa6af; the ink files are #1b0e14 (`text-primary` in light), with the right petal at 72%. The wordmark is Instrument Sans Regular, outlined, tracked +2%. Dark files sit on `bg` #0b0709; light files on #f7f2f4.
